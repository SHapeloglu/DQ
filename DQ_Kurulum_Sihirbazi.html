ADIM 1

Gereksinimler

Başlamadan önce şunların kurulu olduğunu kontrol et.

Zorunlu
  • Python 3.8 veya üzeri kurulu olmalı
  • MySQL 8.0 kurulu ve çalışıyor olmalı
  • pip (Python paket yöneticisi) kurulu olmalı
Opsiyonel
  • Apache Airflow 2.7.x — Docker ile kurulu (Airflow entegrasyonu için)
  • Power BI / Qlik Sense — BI bağlantısı için
Versiyon kontrol komutları
python --version
pip --version
mysql --version
ADIM 2

MySQL veritabanı oluştur

DQ sonuçları ve kuralları MySQL'de saklanır. Tek seferlik kurulum.

MySQL Workbench veya komut satırından çalıştır
CREATE DATABASE dq CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
Komut satırından bağlanmak istersen
mysql -u root -p
⚠️  Şifreni sorduktan sonra yukarıdaki CREATE DATABASE komutunu yapıştır.
✓  Veritabanı oluşturulunca DQ ilk başlatmada tabloları otomatik yaratır, elle tablo oluşturmak gerekmez.
ADIM 3

Python paketlerini kur

dq_web_wizard.zip'i bir klasöre çıkar, o klasöre gir ve aşağıdaki komutu çalıştır.

Klasöre gir
cd dq_web
Paketleri kur (tek komut)
pip install fastapi uvicorn jinja2 python-multipart pymysql python-dotenv tomli pydantic
Paket açıklamaları
  • fastapi — Web API ve arayüz framework'ü
  • uvicorn — Uygulama sunucusu
  • jinja2 — HTML şablon motoru
  • pymysql — MySQL bağlantısı
  • python-dotenv — .env dosyası desteği
  • tomli — TOML dosyası okuma (Python 3.8-3.10 için)
  • pydantic — Veri doğrulama
ADIM 4

Bağlantı ayarları

MySQL bağlantı bilgilerini gir. Bu bilgiler .env dosyasına yazılacak.

MySQL bağlantı bilgileri
.env dosyası içeriği — kopyala yapıştır
DB_HOST=localhost DB_PORT=3306 DB_USER=root DB_PASSWORD=root DB_NAME=dq APP_HOST=0.0.0.0 APP_PORT=8000
ℹ️  dq_web klasöründeki .env dosyasını metin editörü ile aç, içeriği değiştir.
ADIM 5

Uygulamayı başlat

dq_web klasöründeyken aşağıdaki komutu çalıştır.

Uygulamayı başlat

ADIM 6 — OPSİYONEL

Airflow entegrasyonu

Airflow kullanmıyorsan bu adımı atlayabilirsin.

dq_airflow.zip'den şu dosyaları kopyala
  • plugins dq_operator.py → apache-airflow-docker\plugins\dq_operator.py
  • dags dq\ klasörü → apache-airflow-docker\dags\dq\
  • config checks.toml → apache-airflow-docker\dags\checks.toml
  • config orders.csv → apache-airflow-docker\dags\orders.csv
  • dags example_dag.py → apache-airflow-docker\dags\example_dag.py
Docker'ı yeniden başlat
cd C:\Users\yeliz\Desktop\apache-airflow-docker docker-compose restart
Scheduler'a tomli kur

Docker Desktop → Containers → airflow-scheduler → Exec sekmesi:

pip install tomli
ADIM 7 — OPSİYONEL

BI araç bağlantısı

Power BI, Qlik veya Superset ile DQ sonuçlarını görselleştir.

Power BI — OData bağlantısı
  • Power BI Desktop'ı aç
  • Veri Al → OData Akışı seç
  • URL gir: http://localhost:8000/odata/Results
  • Bağlan ve tabloları yükle
Qlik Sense — REST bağlantısı
  • Yeni bağlantı oluştur
  • REST Connector seç
  • URL: http://localhost:8000/api/results
CSV export (her BI aracı için)
http://localhost:8000/api/results.csv
